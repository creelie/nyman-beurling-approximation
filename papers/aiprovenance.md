# AI provenance

The published source supplied the topic, author list and earlier manuscript. This revision used OpenAI Codex for source review, mathematical derivations, independent arithmetic checks, code, diagrams, bibliography verification and editorial preparation. The text therefore combines supplied human-authored material with AI-generated material. Only the named human researchers are listed as authors.

The exact check scope and outputs are in checks/results.json. Tests support finite identities; the mathematical arguments for arbitrary parameters are in the manuscript. No Lean formalization, certified originality, guaranteed journal acceptance or resolution of an open problem beyond the stated theorem scope is claimed. Human-understanding declarations must reflect the submitting authors’ actual review; this package does not invent a new declaration on their behalf.
